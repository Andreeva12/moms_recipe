# moms_recipe — автотесты

Автотесты QA для проекта «Мамины рецепты».

| Папка | Что внутри | Стек |
|---|---|---|
| [`web/`](web) | UI- и API-тесты админки | Playwright (JavaScript), Page Object Model |
| [`mobile/`](mobile) | Тесты мобильного приложения | Appium + pytest (Python) |

Тесты запускаются только вручную (см. README в каждой папке). Автозапуска
и отправки отчётов нет. Логины и пароли берутся из переменных окружения
(`.env`, образец — `.env.example`) и в репозиторий не попадают.
